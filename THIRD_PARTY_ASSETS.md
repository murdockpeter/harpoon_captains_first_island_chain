# Third-party model assets

This ledger records the provenance and redistribution status of authored models currently used by
Harpoon Captain's Edition. All platform models currently render procedurally. The P-8A STL is
retained in the project but its runtime use is suppressed.

### P-8A Poseidon STL

- Supplied by the project owner in `Assets/models/P8.stl`, subsequently moved to
  `Assets/Resources/Models/P8.stl` for runtime loading.
- Original source and redistribution license: pending confirmation from the project owner.
- Current use: none. Scenario 9 currently displays the generated P-8A model.

The P-8 file must not be included in a public binary/source release until its redistribution
license is recorded here.

## Future acquisition policy

Models described as merely "free" are not sufficient. Before a new asset is committed, record
its original page, author, exact license, retrieved file, and any modifications here. Avoid
no-derivatives licenses for assets that need orientation, scaling, conversion, or optimization.
Keep the procedural model as a fallback so missing optional art never blocks a match.
